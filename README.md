# KhoaResume

A responsive copywriting portfolio with a retro desktop-window look.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static web server.

## Personalize

Update the introduction, project details, and contact information in `index.html`.
The portfolio images are served from the linked Wix portfolio; the layout, checkerboard
background, and window-inspired styles are in `src/styles.css`.
